 𝗪𝗵𝗮𝘁 𝗶𝘀 𝗮𝗻 𝗔𝗣𝗜?

 An API (Application Programming Interface) allows two applications to communicate with each other.

 𝗥𝗲𝗮𝗹-𝗟𝗶𝗳𝗲 𝗔𝗻𝗮𝗹𝗼𝗴𝘆

Think of a restaurant:

𝗖𝘂𝘀𝘁𝗼𝗺𝗲𝗿 → Client Application
𝗪𝗮𝗶𝘁𝗲𝗿 → API
𝗞𝗶𝘁𝗰𝗵𝗲𝗻 → Server/Database

 𝗪𝗵𝗮𝘁 𝗶𝘀 𝗮 𝗥𝗘𝗦𝗧 𝗔𝗣𝗜?


A REST API is a web service that follows REST principles and uses HTTP methods to exchange data between client and server.
 
𝗥𝗘𝗦𝗧 𝗔𝗿𝗰𝗵𝗶𝘁𝗲𝗰𝘁𝘂𝗿𝗲


+------------+       HTTP Request       +------------+
|   Client   | -----------------------> |   Server   |
| (Browser)  |                          |  REST API  |
+------------+ <----------------------- +------------+
              HTTP Response

| Method | Purpose             | Example              |
| ------ | ------------------- | -------------------- |

## POST Request Example

import requests

url = "https://jsonplaceholder.typicode.com/posts"

data = {
    "title": "Python",
    "body": "Learning APIs",
    "userId": 1
}

response = requests.post(url, json=data)

print(response.status_code)
print(response.json())


Output:

```json
{
  "title":"Python",
  "body":"Learning APIs",
  "userId":1,
  "id":101
}
```

---

## PUT Request Example


import requests

url = "https://jsonplaceholder.typicode.com/posts/1"

data = {
    "title": "Updated Title"
}

response = requests.put(url, json=data)

print(response.json())

#Complete Workflow Example

Weather Application Using API

import requests

city = "Hyderabad"

url = f"https://api.example.com/weather?city={city}"

response = requests.get(url)

if response.status_code == 200:
    data = response.json()

    print("City:", data["city"])
    print("Temperature:", data["temperature"])
    print("Humidity:", data["humidity"])
else:
    print("Error fetching data")

# Interview Questions

### 1. What is REST API?

A web service that allows communication between client and server using HTTP methods.

### 2. What is JSON?

A lightweight data format used for data exchange between systems.

### 3. Difference between GET and POST?

* GET retrieves data.
* POST sends data to create new resources.

### 4. What does `response.json()` do?

Converts JSON response into a Python dictionary.

### 5. Why use the Requests library?

It simplifies sending HTTP requests and handling API responses in Python.
